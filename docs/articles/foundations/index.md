# Foundations

*The building blocks underneath every eSIM specification: how data is encoded, how it moves to the chip, and how the pieces fit together.*

Most of this knowledge base is organised by GSMA specification. But a handful of concepts cut across all of them. ASN.1 encoding, smart-card APDUs, and modem AT commands show up in SGP.02, SGP.22, and SGP.32 alike. These articles explain those shared foundations so the spec-specific articles can focus on what makes each one different.
